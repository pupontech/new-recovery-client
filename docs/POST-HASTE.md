# Original Post Haste Approach

Post Haste: <https://www.digitalrebellion.com/posthaste/> — Digital Rebellion's free project/folder-template application.

The workflow was originally discussed as a [Post Haste](https://www.digitalrebellion.com/posthaste/) project template.

The desired structure was:

```text
Clients
└── Client Name
    ├── Already on card
    ├── Disk Drill
    ├── FS-Long
    ├── FS-Short
    └── RS
```

The Post Haste concept was:

1. Keep `Clients` as the fixed project destination.
2. Use the client's name as the project/client folder.
3. Import the five standard subfolders into a Post Haste template.
4. Create a new project for each recovery client.

A reference template ZIP was also created during development containing:

```text
Already on card
Disk Drill
FS-Long
FS-Short
RS
```

The final utility in this repository replaces that process with a direct Windows integration:

```text
Right-click
→ New Recovery Client
→ Enter client name
→ Create the full folder structure
```

Post Haste is therefore optional and is not required by this repository.
