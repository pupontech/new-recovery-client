# Changelog

## 1.0.0 - 2026-10-06

### Added
- Windows Explorer right-click action: **New Recovery Client**.
- Support for folder-background, folder, and desktop-background context menus.
- Start Menu launcher.
- Configurable permanent Clients root.
- Client-name prompt.
- Standard recovery folders:
  - Already on card
  - Disk Drill
  - FS-Long
  - FS-Short
  - RS
- Existing-client confirmation.
- Invalid-character cleanup.
- Reserved Windows-name validation.
- Runtime logging.
- Installer, uninstaller, and test launcher.
- GitHub-ready documentation.
- Reference folder template.
- GitHub issue template and PowerShell syntax workflow.

### Historical notes
- Initial workflow was based on a Post Haste folder template.
- A direct Windows implementation was later created so Post Haste is no longer required.
