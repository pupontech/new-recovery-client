# Release Checklist

- [ ] Update `VERSION`.
- [ ] Update `CHANGELOG.md`.
- [ ] Confirm `README.md` matches current behavior.
- [ ] Test `Install.cmd` on Windows 11.
- [ ] Test Start Menu launch.
- [ ] Test Explorer right-click launch.
- [ ] Test Desktop right-click launch.
- [ ] Test client creation with spaces in the name.
- [ ] Test an existing client folder.
- [ ] Test invalid filename characters.
- [ ] Test a reserved name such as `CON`.
- [ ] Test `Uninstall.cmd`.
- [ ] Confirm existing client data remains untouched after uninstall.
- [ ] Create the GitHub release ZIP.
